# Hub de Componentes React

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist

Estrutura: `src/Intro.jsx` (scroll de apresentação), `src/Catalog.jsx` (carrossel),
`src/Detail.jsx` (descrição + código para copiar), `src/data/catalog.jsx` (lista de componentes)
e `src/components/` (cada componente com seu .jsx e .css).
